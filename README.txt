ALPHONSA SPICES website — GitHub Pages edition

FILES
- index.html: complete responsive website. No build tools required.

PUBLISH TO GITHUB PAGES
1. Open your GitHub repository (or create a new public repository, e.g. alphonsa-spices-website).
2. Upload index.html to the repository root and commit to the main branch.
3. Open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, branch main, folder /(root), then Save.
5. Once GitHub Pages publishes the site, enter alphonsaspices.in in the Custom domain field and save.
6. At your domain registrar, configure the DNS records exactly as shown in GitHub's current custom-domain instructions. DNS changes can take time to propagate. Enable Enforce HTTPS after the domain is verified.
